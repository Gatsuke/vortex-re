# Native-format fixtures

Minimal, structurally valid binaries used by Vortex-RE's parser tests.
Every file is generated by [`gen.py`](gen.py) (Python 3 stdlib only) and
reproduces byte-for-byte on re-run, so the fixtures can be regenerated and
diffed at any time.

| Fixture | Format | Exercises |
| --- | --- | --- |
| `elf64-demo` | ELF64 LSB, ET_EXEC, x86-64 | header, 5 sections, `.dynsym` with 2 undefined imports (`puts`, `malloc`) |
| `elf32-demo` | ELF32 LSB, ET_DYN, i386 | 32-bit layout, 1 undefined import (`printf`) |
| `pe64-demo.exe` | PE32+ (x86-64) | DOS/COFF/optional headers, 2 sections, import table: `KERNEL32.dll!CreateFileW`, `USER32.dll!MessageBoxW` |
| `pe32-demo.exe` | PE32 (i386) | 32-bit optional header, import table: `msvcrt.dll!printf` |
| `dotnet-demo.exe` | PE32+ + CLR | data directory 14, CLI header (runtime 2.5), BSJB metadata root (`v4.0.30319`) with `#~`, `#Strings`, `#US`, `#GUID`, `#Blob` streams. Stream *headers* are valid; table contents are placeholders — the fixture is for inventory-level parsing. |
| `classes-dex` | DEX version 035 | header, string/type/proto/method/class-def tables, 1 class (`Ldemo/Sample;`), valid adler32 checksum and SHA-1 signature |

All fixtures were cross-validated with independent tools when they were
created: `readelf` for the ELF files, `objdump` for the PE files, and
recomputed checksums for the DEX. They contain no third-party code — they
are generated data, not compiled software, and carry no upstream licensing.

## Regenerating

```sh
python3 gen.py
```
